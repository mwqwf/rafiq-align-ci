# 🦾 `jobs/` — يدُ الوكيل السحابيّ

> **القاعدة:** ما تعذّر على الوكيل في صندوقه **يُكتب هنا سكربتاً ويُدفع**، فيُنفَّذ على عدّاء
> GitHub **بشبكةٍ مفتوحة**، وتعود مخرَجاتُه ملفّاً في `results/` يقرؤه بـ`git pull`.

## كيف يستعمله الوكيل

1. اكتب `jobs/<اسم>.sh` — سكربت bash عاديّ.
2. أودِعه وادفعه إلى `main` **بمسارٍ صريح** ⇒ يشتعل `agent-job` تلقائيّاً على **ما تغيّر وحدَه**.
3. انتظر، ثمّ `git pull` واقرأ `results/LATEST_job.md` (‏أو `results/job_<الشوط>.md`).

⛔ **ولا يُقتل الشوطُ بفشل سكربت** — يُسجَّل رمزُ خروجه ويمضي إلى التالي. **والفشلُ يُكتب فشلاً.**

## ما يجده السكربتُ جاهزاً

| | |
|---|---|
| الشبكة | **مفتوحةٌ بلا حجب** — `dl.google.com` · `r2.dev` · أيُّ مضيف |
| بايثون | 3.11 ومعه `numpy` · `soundfile` · `scipy` · `boto3` |
| جافا | Temurin 17 |
| `ffmpeg` | مثبَّت |
| بيانةُ R2 | في البيئة: `R2_ENDPOINT` · `R2_ACCESS_KEY_ID` · `R2_SECRET_ACCESS_KEY` · `R2_BUCKET` |
| المستودعُ الخاصّ | `$QR_DIR` — **إن وُجد السرُّ `QR_READ_TOKEN`**، وإلّا فالمتغيّرُ فارغٌ ولا يفشل الشوط |

## ⛔ حدودٌ تُحترم

- **لا تكتب في `timings*` ولا في مستودع الفهرسة** — لها جلساتُها.
- **ولا تُنفق دقائقَ في المستودع المدفوع** — هذا المستودعُ عامٌّ ودقائقُه مجّانية.
- واجعل مخرَجَ سكربتك **صغيراً ومقروءاً**: آخرُ 400 سطرٍ هي ما يُحفظ.
