# مود حرّاس المالك (`rafiq-guards`)

خيوط المشاريع السحابية تبدأ في `/home/user` لا في المستودع، فلا تُحمَّل فيها هوكات `.claude/settings.json`.
هذا المود يُحمَّل أياً كان مجلد البدء، فيفعل الآتي:

1. **جسر الحراس:** يشغّل هوكات `PreToolUse` من إعدادات كل مستودع مستنسخ في `/home/user` كما هي. ولا يجسر هوكات مستودع بدأت الجلسة داخله، ولا يشغّل الحارس نفسه مرتين.
2. **فرض العربية فيما يراه المالك:** رسائل الخيط وبطاقات القرار وقائمة التقدم، وعناوين طلبات الدمج ووصفها وتعليقات GitHub، وسطر عنوان رسالة الإيداع.
3. **منع `git add -A` و`git add .` و`git commit -a`:** ويعيد معه قائمة الملفات المتغيرة.
4. **لوحة «حرّاس رفيق» وأمر `/rafiq-guards`:** يعرضان ما رُدّ في الجلسة.

## التفعيل في كل المشاريع والجلسات السحابية

النسخة المرجعية في المستودع العام `mwqwf/rafiq-align-ci` (يُستنسخ بلا صلاحية). وفي كل بيئة سحابية
(إعدادات المشروع ← بيئة السحابة ← الترس) يُضاف أمران مرةً واحدة:

سطر في **سكربت الإعداد**:
```
git clone -q --depth 1 https://github.com/mwqwf/rafiq-align-ci /opt/owner-mods || true
```

ومتغير في **متغيرات البيئة**:
```
CLAUDE_CODE_PLUGIN_DIRS=/opt/owner-mods/.claude/mods/rafiq-guards
```

فيجسر المود هوكات كل مستودع مستنسخ في `/home/user`، ويفرض العربية ويمنع الإيداع بالجملة في كل جلسة.
وعلى الحاسوب المحلي: `claude --plugin-dir <المسار>/.claude/mods/rafiq-guards`.

## الفحص

```
claude plugin validate .claude/mods/rafiq-guards
claude plugin test .claude/mods/rafiq-guards
```
